## 测试前准备（2 分钟）

- 手机 **Chrome** 打开线上地址；确认加载的是新版（应用内无版本号显示，用下面两条判据）：
  - 训练页的动作列表是**一张大卡里分行**（发丝线分隔），每行右侧「开始」是**浅蓝底深蓝字**——若看到每个动作各自一张小白卡、每行一个实心蓝按钮，那是 v0.2.25 及以前的旧版，缓存没穿透，强制刷新或换无痕窗口；
  - 知识页七个分类标题是**加粗深色**的扫读锚点，不是小灰字。
- 三轮环境：
  - **第一轮用无痕窗口**（Chrome 菜单 → 新建无痕式标签页）：模拟全新用户，关窗即清空，放心随便点；
  - **第二、三轮用正常窗口**：如果手机里已有日常数据，先完成第 6 项备份下载再往下做（这本身就是测试项）。
- ⚠️ 安全注意：测 `tel:120` 会弹出拨号盘，**看一眼能唤起就按取消，不要真的拨出去**。
- ⚠️ 恢复测试会用备份**覆盖本机数据**，靠「恢复点 + 撤销一次」保护（第 9 项专门验它）；「清空数据」放在最后、且先确认手里有刚下载的备份。

## 第 0 组 · 朗读听感专项（约 5 分钟，本轮最高优先）

这次改的是「念出来像不像人话」，判据是**耳朵**而不是屏幕。找个安静环境、把音量开到听得清。

- [ ] 0-1. 知识页 → 《防复发最重要的五件事》→ 「🔊 听一遍」，**从头听到「控制血压」那一段**，重点三处：
  - 小标题「1. 按时服药，绝不擅自停药」念完要**停一下**再念后面的正文，不能连成一句破句（这是改动前最明显的毛病）；
  - 血压目标念成「**高压130、低压80毫米汞柱**」，不能是「130斜杠80」或把 mmHg 拼成字母；
  - 「阿司匹林**加**氯吡格雷」的「加」要念出来。
- [ ] 0-2. 同一篇里听「糖化血红蛋白」和「低密度脂蛋白胆固醇」：应念中文全称，**不能出现** "H b A 1 c"、"L D L C" 这种拼字母。
- [ ] 0-3. 句子之间有**换气感**，不是一句紧接一句的机关枪节奏；但也不该慢到拖沓。
- [ ] 0-4. 训练页任一动作 → 引导页 → 「🔊 听一遍」，听「建议量」那句：`10～15次×2组` 要念成「**10到15次，做2组**」，不能是「10 15次乘2组」。
- [ ] 0-4a. 整篇听下来**不该念出 HTML 标签**（不出现 "p"、"li"、"尖括号" 之类的杂音）。
- [ ] 0-5. 朗读中途按「⏹ 停止朗读」→ **立刻**安静（不能等当前句念完），按钮复原；再点一次能重新开始。
- [ ] 0-6. 朗读进行中直接切到别的底部标签 → 声音立刻停（iOS 上漏了会继续念上一页）。
- [ ] 0-7. 设置 → 看有没有「朗读声音」这一档：
  - **iOS 通常只有一个中文音色（婷婷），因此这一档不显示是正确的**，不是 bug；
  - 若显示了（安卓多见），点不同音色应**立刻用新声音念一句**，按钮上是中文名（如「晓晓（女声）」），**不该出现** `Microsoft ... Online (Natural)` 这种长英文；
  - 选一个 → 用 ✕ 关掉设置（不按「保存设置」）→ 重开设置，选中的还是它 → 刷新页面后再听一遍，仍是这个声音。
- [ ] 0-8. 朗读语速改成「快」→ 点「再听一句」确认变快；关掉设置重开，仍停在「快」。

> 若 0-1 里小标题和正文仍粘成一句，或 0-4 仍念「乘」，说明手机拿到的是缓存旧版，先强制刷新再复测。
