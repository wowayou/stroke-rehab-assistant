# 脑梗康复助手 🌱

面向**脑梗（缺血性脑卒中）恢复期患者及家属**的家庭康复辅助工具。

一个零依赖的纯静态 Web 应用：没有后端、没有账号、没有埋点，**所有数据只保存在本机浏览器（localStorage）里**，不上传任何服务器。适老化设计（大字体、大按钮、高对比度、可调三档字号），手机优先。

## 为什么做这个

脑梗患者出院后普遍面临四个问题，本应用逐一对应：

| 痛点 | 对应功能 |
|---|---|
| 回家后不知道怎么练、练不坚持 | **康复训练库**：按康复阶段（卧床/坐位/站立/步行）推荐动作，图文要领 + 计次/计时引导 + 每日打卡与连续天数激励 |
| 二级预防执行差（复发风险高） | **健康记录**：血压/血糖/体重记录、目标值提示、趋势图、一键导出给医生 |
| 漏服药、擅自停药 | **用药核对**：按处方登记药物与时间点，每日勾选，7 天依从率统计 |
| 不认识复发信号，延误送医 | **紧急识别**：BE-FAST + 中风120 口诀，一键拨打 120；9 篇实用科普（防复发、饮食、防跌倒、卒中后抑郁、照护者指南等） |

## 功能一览

- **今日**：今日三件事（测血压、服药核对、康复训练）+ 按阶段推荐的训练组合 + 康复第 N 天/连续坚持天数
- **训练**：5 大类 30+ 个动作
  - 肢体运动（按卧床期/坐位期/站立期/步行期分级）
  - 手部精细（抓握、对指、拧毛巾、捡豆子、翻纸牌）
  - 言语训练（口部操、发音、数数、跟读、命名）
  - 吞咽训练（空吞咽、鼓腮唇部、舌肌，附进食安全警示）
  - 认知训练（4 个内置小游戏：记忆翻牌、顺序点数、颜色辨认、算一算 + 生活化练习）
  - 每个动作：目的、分步要领、建议量、安全注意；计次大按钮 / 倒计时器 / 游戏三种引导模式
- **记录**：血压（高低压双线趋势图 + 140/90 参考线）、血糖（分空腹/餐后）、体重（BMI）；超标分级提示；文本报告导出复制
- **用药**：常用药快捷录入、多时间点、每日按时间分组核对、近 7 天依从率
- **知识**：BE-FAST 紧急卡（一键拨 120）+ 9 篇科普文章
- **设置**：称呼、发病日期、身高、三档字号、数据导出/清空

## 使用方法

方式一：直接双击 `index.html` 用浏览器打开（无需任何安装）。

方式二：任意静态服务器托管，例如：

```bash
cd stroke-rehab-assistant
python3 -m http.server 8080
# 手机与电脑同一 Wi-Fi 时，手机访问 http://<电脑IP>:8080
```

方式三：部署到任意静态托管（Nginx / GitHub Pages / Cloudflare Pages 等），发链接给家人，手机浏览器"添加到主屏幕"即可当 App 用。

> 📱 线上地址（Cloudflare Pages）：**https://stroke-rehab-assistant.pages.dev/** —— 重新部署用仓库根目录的 `deploy.sh`。

> 注意：数据存在浏览器本地，**换设备/清缓存不互通**。重要记录请定期用「导出」功能备份。

## 技术说明

- 纯 HTML/CSS/JS，无框架、无构建、无外部依赖，可离线打开（file:// 协议直接可用）
- `js/data-exercises.js` 训练动作库、`js/data-articles.js` 科普内容 —— 内容与代码分离，方便增改
- `js/storage.js` localStorage 数据层；`js/charts.js` 零依赖 canvas 趋势图；`js/games.js` 认知训练小游戏
- 适老化：基准字号 18px（可调至 22px）、触控目标 ≥48px、高对比度、底部大图标导航

## 医学内容与免责声明

训练动作与科普内容参考《中国脑卒中康复治疗指南》《中国缺血性卒中和短暂性脑缺血发作二级预防指南》等公开指南的通行建议整理，属于**健康教育性质**：

- 本应用**不能替代医生的诊断、治疗和处方**；
- 康复训练应经康复医生/治疗师评估后进行，站立、步行、吞咽相关训练尤其注意安全警示；
- 血压、血糖、血脂目标值以主治医生的个体化要求为准；
- 出现 BE-FAST 任一症状，立即拨打 120。
